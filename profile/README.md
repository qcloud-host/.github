# Intelligence, put to work.

Models. Agents. Compute. Developer tooling for the QCloud AI platform.

[Explore QCloud](https://www.qcloud.host) · [API quickstart](https://www.qcloud.host/api-docs) · [Model catalog](https://www.qcloud.host/models) · [Contact](mailto:info@qcloud.host)

## Build with QCloud

| Library | What you get |
| --- | --- |
| [Python](https://github.com/qcloud-host/qcloud-python) | Typed sync and async clients, streaming, model discovery, and embeddings |
| [TypeScript / Node.js](https://github.com/qcloud-host/qcloud-typescript) | ESM and CommonJS, typed responses, streaming, retries, and cancellation |

Our SDKs use QCloud's OpenAI-compatible inference endpoints. Start with your QCloud API key and an active model ID from the catalog. Tool calling and structured output depend on the selected model.

We are also building Agent Cloud, isolated sandboxes, QCloud Forge, developer connections, realtime voice, and generative media. These products are in development; see their pages for current availability.

## Contribute

Found a bug or have an integration in mind? Open an issue in the relevant SDK repository. For account and service questions, email [info@qcloud.host](mailto:info@qcloud.host).
